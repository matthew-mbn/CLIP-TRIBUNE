# Публикация в TikTok

В CLIP TRIBUNE есть два способа отправки через официальный Content Posting API.

- **Черновик в TikTok:** MP4 передаётся в аккаунт. Во входящих TikTok появится уведомление;
  откройте его, добавьте подпись, музыку и завершите публикацию в самом TikTok.
- **Прямая публикация:** выберите аккаунт, видео, описание, видимость и разрешённые взаимодействия,
  раскройте коммерческий/AI-контент, примите условия и нажмите «Отправить в TikTok».
  Возможности аккаунта и максимальная длительность запрашиваются у TikTok перед отправкой.

## Настройка

Сайт приложения: <https://matthew-mbn.github.io/CLIP-TRIBUNE/>.
Для анкеты разработчика:

- Terms of Service: <https://matthew-mbn.github.io/CLIP-TRIBUNE/terms.html>
- Privacy Policy: <https://matthew-mbn.github.io/CLIP-TRIBUNE/privacy.html>

Для собственного приложения используйте страницы, описывающие именно вашу сборку и владельца.

1. В [TikTok for Developers](https://developers.tiktok.com/) зарегистрируйте приложение.
2. Добавьте Login Kit для **Desktop** и Content Posting API.
3. Зарегистрируйте точный Redirect URI `http://127.0.0.1:8765/api/tiktok/callback`.
4. Получите доступ к `user.info.basic` и `video.upload` (черновики), либо `video.publish` (Direct Post).
5. Введите собственные Client Key и Client Secret в «Настройки» → «TikTok» и сохраните.
6. На экране TikTok выберите способ отправки и нажмите «Подключить». Войдите в браузере.
7. Выберите готовое видео из библиотеки. При смене способа отправки может потребоваться
   переподключение с другим разрешением.

### Первое тестирование и App review

Создайте Sandbox в TikTok for Developers и добавьте свой аккаунт в **Target users**.
Настройте продукты и Desktop Redirect URI внутри Sandbox, затем нажмите **Apply changes**.
В CLIP TRIBUNE вводятся ключи именно выбранного Sandbox; не смешивайте их с Production.
Сначала проверьте подключение и загрузку во входящие на тестовом аккаунте.

Для проверки Production TikTok запрашивает описание каждого продукта/разрешения и настоящую
видеодемонстрацию всей интеграции. Запишите подключение аккаунта, выбор ролика, настройки,
отправку и результат. Покажите каждый запрошенный scope; не заявляйте непроверенные возможности.
Создание Sandbox и публикация документов не являются одобрением приложения.

`Verify domains` у Content Posting API относится к `PULL_FROM_URL`. CLIP TRIBUNE передаёт
локальный файл через `FILE_UPLOAD`. Подтверждение владения URL сайта и документов для
анкеты выполняется отдельно через **URL properties**.

Ключи не зашиты в EXE. Секрет и токены шифруются в локальной базе; пароль TikTok приложение не запрашивает.
Публичная массовая поставка с единым Client Secret потребует отдельного серверного хранилища секретов;
локальная версия использует credentials пользователя.

## Ограничения платформы и статусы

TikTok требует одобрения API-разрешений. Непроверенный Direct Post ограничен приватными аккаунтами,
видимостью SELF_ONLY и тестовым лимитом пользователей. Для публичной видимости нужен аудит TikTok.
Правила аудита исключают утилиты только для внутренних аккаунтов владельца/команды; одобрение
личного приложения не гарантируется. Режим загрузки в черновики тоже требует доступа к video.upload.

«Обработка TikTok» означает, что файл передан, но публикация ещё не подтверждена. «Во входящих TikTok»
означает, что нужно завершить публикацию в TikTok. Только PUBLISH_COMPLETE даёт статус «Опубликовано».
После сбоя используйте «Проверить статус»; автоматического повторного создания поста нет.
Один ролик можно поставить в TikTok один раз на аккаунт. История YouTube независима.
Глобальная остановка отменяет локальную очередь и дальнейшую передачу файла, но не удаляет
пост, уже принятый TikTok. Управляйте такими постами в TikTok.

Тесты проверяют OAuth/PKCE, обновление токенов, права, параметры, загрузку и статусы с подменой API.
Во время настройки владелец подтвердил работу Sandbox. Автоматическая проверка реальной
публикации не выполнялась; одобрение Production со стороны TikTok не подтверждено.

Замена EXE на новую версию сохраняет ключи и аккаунты в локальном хранилище AppData.
При переходе из Sandbox в Production нужны credentials соответствующего окружения
и новое подключение аккаунта; это отдельное изменение настроек, не обычное обновление EXE.

## Где читать код

- `backend/tiktok.py` — авторизация, проверка параметров, передача файла, статусы.
- `backend/tiktok_routes.py` — локальные HTTP-маршруты.
- `desktop/tiktok_page.py` — интерфейс Tkinter.
- `tests/test_tiktok.py` — примеры успешных и ошибочных ответов платформы.
