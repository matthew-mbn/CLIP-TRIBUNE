## CLIP TRIBUNE 0.7.1

Новые нарезки эфиров и видео, скачанных через приложение, называются **`TWITCH: ник`**
или **`YOUTUBE: ник`**. В заголовке используется автор исходного видео.

- Для YouTube берётся ник без `@`; если ник недоступен — название канала.
- Для Twitch-клипов определяется стример, а не зритель, нажавший «Создать клип».
- Название сохраняется при автопубликации в YouTube и в шаблоне подписи TikTok `{title}`.
- Новая полная запись эфира сохраняет сведения об авторе для последующего монтажа.
- Если сервис не отдал имя, показывается «автор не определён».

Закройте старую версию и запустите новый EXE. Ключи, подключения и библиотека сохраняются.
Старые клипы и публикации не переименовываются. Для локальных и ранее скачанных файлов
без сведений об авторе остаётся прежнее создание названий.
