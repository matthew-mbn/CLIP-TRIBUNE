## CLIP TRIBUNE 0.6.0

Добавлена экспериментальная автопубликация нарезок эфира в TikTok: один раз настройте
серию в разделе **Эфиры**, затем программа записывает трансляцию, отбирает моменты,
создаёт клипы и отправляет их без подтверждения каждого ролика.

- Аккаунт, видимость, подпись с `{title}`, интервал, лимит и маркировки выбираются перед записью.
- При ошибке отправка приостанавливается, запись продолжается. Есть отдельная остановка серии.
- История предотвращает повторную загрузку одного клипа в один аккаунт.
- Исправлена проверка `video.publish` / `video.upload`; повторное подключение обновляет форму.
- Ошибки TikTok теперь показывают подробности причины, без ссылок с секретами.

Режим выключен по умолчанию. Он не соответствует процессу согласия TikTok App Review;
одобрение и публичная публикация не гарантируются. Для непроверенного Direct Post доступен
только `SELF_ONLY`, для публичной видимости нужен аудит TikTok.

Скачайте **CLIP.TRIBUNE.exe** либо ZIP, закройте старую версию и запустите новую.
Ключи, аккаунты и библиотека в AppData сохраняются. EXE без цифровой подписи издателя;
контрольные суммы — в SHA256SUMS.txt.
