## CLIP TRIBUNE 0.7.0

Автопубликация нарезок эфира теперь работает в **TikTok, YouTube или обоих сервисах**.
В разделе **Эфиры → 04 / Автопубликация** включите нужные переключатели.
Для каждой платформы задаются свой аккаунт, видимость, интервал, лимит и сведения о контенте.
Серия разрешается перед записью; подтверждать каждый клип не требуется.

- Ошибки и остановка одной платформы не отключают другую или запись.
- YouTube-серия не запускает старые задания ручной очереди. Истории платформ независимы.
- Исправлено несовпадение размера единственной части и целого файла в TikTok,
  вызывавшее **The chunk size is invalid**. После явного отказа HTTP 400 без идентификатора
  загрузки можно вручную отправить тот же ролик снова.
- Сетевые ошибки TikTok теперь показывают тип сбоя без секретов из исключения.

Закройте старую версию и запустите новый EXE. Ключи, аккаунты и библиотека сохраняются.
Новые серии YouTube по умолчанию выключены. Обновление не запускает неудачные отправки.

Автоматический режим TikTok экспериментальный и не соответствует описанному TikTok
процессу просмотра и согласия для каждого поста. Возможности и ограничения обеих платформ
зависят от их разрешений и квот. Внешние API в тестах подменены; реальная успешная отправка
в пользовательские аккаунты в рамках этой проверки не заявляется.
