## CLIP TRIBUNE 0.8.0

- Сохранение выбранных роликов в свою папку и автоматическое копирование новых результатов.
- Пауза видео и основного звука на время разовой рекламы, затем продолжение без потери кадров.
- Стрим с уже встроенной вебкой сверху и отдельный игровой файл снизу — в эфирах и студии.
- Локальное распознавание речи, редактор текста и таймингов, отключение отдельных фраз,
  четыре стиля и настоящий кадр предпросмотра. Результат сохраняется отдельной копией.
- Живой предпросмотр вебки: соединение остаётся открытым, пока пользователь ждёт окончания рекламы Twitch.

Закройте старую версию и запустите новый EXE. Библиотека, ключи и подключения сохраняются.
Для локального распознавания один раз скачайте модель 148 МБ через настройки или редактор субтитров.

[Инструкции](https://github.com/matthew-mbn/CLIP-TRIBUNE/blob/main/docs/editing.md).
