# Необязательные провайдеры

## SpeechProvider

`SPEECH_API_URL` — URL вашего отдельного сервиса распознавания. Основной backend использует Python 3.15; ML-сервис может работать в другой версии Python и другом окружении.

POST `multipart/form-data`, поле `file`, заголовок `Authorization: Bearer <SPEECH_API_KEY>`. Ответ:

```json
{"segments": [{"start": 1.2, "end": 3.8, "text": "Пример распознанной речи"}]}
```

Времена относятся к исходному видео. Студия переносит их в координаты выбранного клипа, создаёт SRT и встраивает текст через libass. Поддерживаются русский и английский, если их поддерживает ваш сервер. Выделение активных слов ещё не реализовано.

Передача исходника происходит только при выборе субтитров и наличии настроенного URL. Если обработчик расположен в облаке, исходник будет отправлен на этот сервис. По умолчанию URL пустой, сетевого распознавания нет.

## Content Intelligence

`AI_API_URL` принимает POST JSON в формате chat completions, `AI_MODEL` указывает модель. Заголовок `Authorization: Bearer <AI_API_KEY>`. Передаются тема, признаки отбора и имеющаяся транскрипция; сам видеофайл не передаётся. Ответ: `choices[0].message.content` — JSON-строка с `titles`, `description`, `hashtags`, `thumbnail_idea`.

При ошибке автоматически применяются шаблонные метаданные. Они не приписывают видео распознанные события. LLM также требует проверки фактов пользователем.

## Видео и анимация

`VideoAnalysisProvider` описывает контракт будущей семантической модели. В MVP такая модель не установлена и не вызывается.

`animation_engine.py` содержит интерфейсы ScriptGenerator, StoryboardGenerator, CharacterProvider, SceneRenderer, VoiceProvider, VideoComposer. Реализован только самостоятельный процедурный пример, не произвольная генерация мультфильмов по тексту.
